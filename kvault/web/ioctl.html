How the app asks the kernel for help

An IOCTL (input/output control) is a named request an application sends to a device driver. KernelVault uses these requests to prepare, encrypt, or decrypt data.

This page is a simulation. Try the requests below to see how the driver state changes. It does not call a real kernel driver.
  1. 1

    The app asks

    It sends a named request with any required data.

  2. 2

    The driver checks

    It validates the request and uses the kernel crypto service.

  3. 3

    The app gets a result

    The driver returns a status and, for data requests, the transformed bytes.
