User-Space Application Engine (C++20)

Virtual Address Space · Pageable RAM
POSIX Process Entry & Signal Handling sigaction(SIGINT)

Captures signals, prevents core dumps via prctl(PR_SET_DUMPABLE, 0), masks terminal echo during passphrase ingestion.

Stack Hygiene: Zeroed via explicit_bzero
KDF KeyDerivation Subsystem 100,000 It

Zero-dependency PBKDF2-HMAC-SHA256 engine. Derives 256-bit AES key and 256-bit HMAC key from variable-length passphrase with hardware salt.

Key Buffer: Ephemeral · Transient
VFS Advisory File Lock Manager POSIX fcntl

Move-only RAII lock wrapping fcntl(F_SETLK/F_SETLKW). Guarantees multi-process exclusion on record files (F_WRLCK for mutation, F_RDLCK for inspection).

Lock State: No Active Locks
IO AtomicFileWriter (3-Phase Commit) 0600 Perms

Writes to temporary file (.tmp.<pid>), forces hardware writeback cache flush via fsync(), and commits via atomic renameat2(RENAME_NOREPLACE).

Transaction: Standby · Consistent
ENGINE VaultManager Orchestrator 64 KiB Chunks

Segments binary payload into 64 KiB chunks, packs the 96-byte authenticated header, dispatches IOCTL transforms, and verifies HMAC-SHA256 tags in constant-time.

Chunk Buffer: Idle

RING 0

Linux Kernel Subsystem (GPL v2)

Pinned Kernel Pages · Non-Swappable
CDEV Character Device Driver /dev/kvault

Registered dynamically via alloc_chrdev_region() with file operations table: open, release, unlocked_ioctl, read, write.

Concurrency Gate: atomic_cmpxchg(&busy, 0, 1)
KMALLOC Pinned Cryptographic Context kzalloc(GFP_KERNEL)

Holds cipher session state, active 256-bit key, and IV in physical RAM. Immune to user-space ptrace, /proc/pid/mem reads, and swap file dump leakage.

Memory Hygiene: memzero_explicit() verified
CRYPTO Linux Kernel Crypto API crypto_alloc_skcipher

Instantiates in-kernel AES-256-CBC cipher transform ("cbc(aes)"). Hardware accelerated via AVX/AES-NI instruction sets when available.

Cipher Transform: Sync CBC skcipher
DMA Scatterlist Mapping Engine sg_init_one

Wraps 64 KiB kernel buffers into scatterlist vectors (struct scatterlist) for zero-copy hardware DMA engine dispatch via skcipher_request.

Throughput Status: Channel Ready
BLOCK Block I/O & Journaling Layer Ext4 / XFS Journal

Underlying journal commit ensures metadata persistence. Hardware barrier flushes NVMe volatile write cache to permanent non-volatile flash cells.

Crash Consistency: POSIX ACID Assured
